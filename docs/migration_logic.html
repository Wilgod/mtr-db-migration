Consolidation line

    Consolidation · logic 1

    Renumbering IDs without collisions

    Every source numbers its IDs from 1. Each source gets an offset equal to the sum of the highest IDs of the sources listed before it, so each source lands in its own unbroken range. Change the numbers to try it.

    Consolidation · logic 2

    When two databases hold the same record

    The source listed first in sources.json wins. Every row that is not copied 1:1 is written to _merge.conflict_log, so nothing disappears without a record.

    Finding the file for each uploaded row
